# Aktifkan video ElevenLabs di Cursor (sekali saja)

Koneksi kamu sudah jalan, tapi chat ini cuma dapat tool **Agents**. Video butuh izin tambahan.

1. Buka **Cursor** → **Settings** (⌘,)
2. Ketik di search: **MCP**
3. Klik **ElevenLabs** di daftar server
4. Pilih **Disconnect** atau **Sign out**, lalu **Connect** lagi
5. Browser terbuka → login ElevenLabs → **centang semua**, terutama:
   - **Flows**
   - **Image & Video Generation**
   - **Text to Speech**
6. **Allow** / **Authorize**
7. Tutup settings, buka **Composer / chat baru** di project ini
8. Tulis: *generate video Subsidy Filter pakai ElevenLabs*

Kalau setelah itu masih gagal, kemungkinan role kamu di workspace ElevenLabs tidak boleh generate image/video — minta owner workspace mengaktifkannya.
