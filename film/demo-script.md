# NEAR Hackathon demo — Subsidy Filter

7 scenes. ~75 seconds. English. One ElevenLabs voice. Assemble **1 → 7**.

Reuse what you already have in `stock for video/` when it still matches. Re-record any dashboard take that is the old layout.

| Tool | Use | Do not |
| --- | --- | --- |
| Screen record | Scenes 2–6. Live dashboard. Slider 2.5→2.4 is the one required action. | Terminal, install, face cam |
| ElevenLabs | One take per scene. Same voice, same settings. | Hype / ad voice |
| Google AI Pro | Scenes 1 and 7 only. Still image, 16:9, type on cream. | Charts, fake numbers, fake chain UI |
| Pexels | Optional 2s under Scene 1 or between 1→2. Abstract / desk / city night. | Stock “analytics dashboard”, crypto charts, rocket |

## Setup once

1. Chrome 1920×1080. Hide bookmarks. Dashboard already loaded. Signer multiple **2.5**.
2. ElevenLabs: one calm adult English voice. Stability high, style low, speed ~0.95. Keep that voice for s1–s7.
3. Export each line as `s1.mp3` … `s7.mp3`. Picture as `s1` / `s2.mp4` … matching the scene number.
4. Google AI Pro → Image, 16:9. If letters are wrong, generate again. Do not ask it for a chart.
5. Pexels search if you want a 2s open: `hands typing laptop night`, `city lights bokeh aerial`, `paper documents desk overhead`. Download 1920×1080.
