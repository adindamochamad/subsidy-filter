# NEAR Hackathon demo — Subsidy Filter (64s cut)

One video. Playwright records `dashboard/index.html?film=1` so judges see the same interactive page as the hosted URL.

## Build

1. `make all` from repo root (offline).
2. `cd film && npm install && npx playwright install chromium && npm run film`
3. Output: `film/subsidy-filter-64s.mp4`

Voice: macOS `say` voice Daniel (see `film/audio/build.mjs`). Re-run `npm run film` after copy changes.
